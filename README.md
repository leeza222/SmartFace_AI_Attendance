# SmartFace AI Attendance

SmartFace AI Attendance is an AI powered smart attendance management system built using Computer Vision Face Recognition and Emotion Detection technologies.

The system automatically identifies registered individuals through live camera recognition records attendance with date and time tracks check in and check out activity and performs real time emotion analysis.

Designed for educational institutions workplaces and intelligent monitoring environments this project combines Artificial Intelligence Computer Vision and Automation to create a smart attendance solution.

## Installation

Clone repository

```bash
git clone https://github.com/leeza222/SmartFace_AI_Attendance.git
```

Move into project directory

```bash
cd SmartFace_AI_Attendance
```

Install dependencies

```bash
pip install opencv-python
pip install face-recognition
pip install fer
pip install tensorflow
pip install numpy
```

Run attendance system

```bash
python attendance.py
```

Run emotion detection

```bash
python emotion_detection.py
```
